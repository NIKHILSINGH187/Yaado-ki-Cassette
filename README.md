# यादों की कैसेट — Yaado Ki Cassette 📻

> A viral, aesthetic, ad-free retro Hindi cassette tape & Walkman web player. Stream evergreen Bollywood classics, 90s nostalgia, ghazals, and cozy lo-fi beats with realistic spinning reels and authentic analog atmosphere.

🔗 **Live Site:** [nikhilsingh187.github.io/Yaado-ki-Cassette](https://nikhilsingh187.github.io/Yaado-ki-Cassette/)

---

## ✨ Features

- 📼 **Interactive 3D Cassette Tape** — Real-time rotating spool cogs with magnetic tape that visibly unspools from left to right as the song plays.
- 🔍 **Spotify-Style Live Search** — Instant instant search by song title, singer, movie, era, or lyrics with 1-click playback and "+Q" queue button.
- 📑 **Up Next Queue Management** — Dynamic queue drawer to queue up your favorite songs and auto-play in sequence.
- 🔀 **Shuffle & 🔁 Repeat Modes** — True shuffle randomizer plus 3 repeat modes (Repeat All, Repeat One Track, Repeat Off).
- ❤️ **Liked Songs Library ("मेरी पसंद")** — Heart button on the cassette to save your favorite songs directly into your browser's local storage.
- 📱 **Native Media Session API** — Full lock-screen support on iOS & Android, notification center player, smartwatch integration, and Bluetooth headphone button controls with retro artwork.
- 📜 **Vintage Typewriter Lyrics Sheet** — Read along and sing with retro parchment lyrics cards for classic songs.
- ⌨️ **Pro Keyboard Shortcuts** — Control playback with `Space` (play/pause), `←/→` (seek), `↑/↓` (volume), `L` (like), `S` (shuffle), `R` (repeat), `N` (next), `P` (prev), `F` (flip), and `/` (search).
- ↻ **Flip Tape (Side A ⇄ Side B)** — Click the cassette or the Flip button to physically rotate the cassette 180° in 3D to reveal Side B and switch playlists.
- 🎵 **100% Ad-Free Audio Engine** — Continuous, high-quality audio streaming with zero ads or interruptions.
- 🎛️ **Dual Glowing Analog VU Meters** — Responsive left and right audio level meters dancing in real time.
- ⏱️ **Mechanical Tape Counter** — Classic mechanical digital tape counter that tracks your listening time with a one-touch reset.
- 📻 **Warm Analog Tape Hiss** — Synthesized vintage tape hiss using Web Audio API procedural pink noise.
- ✨ **Lo-Fi / Slowed + Reverb Mood** — One-tap toggle to switch playback into the viral dreamy slowed+reverb aesthetic.
- 💤 **Sleep Timer** — Set 15m, 30m, 45m, or 60m auto-stop timers to fall asleep to classic songs.
- 📁 **Custom Tape Loader** — Load your own MP3 files from your device directly onto the cassette deck.
- 📱 **PWA Installable** — Install directly to your phone's home screen or desktop as a native app with offline capability.
- 💬 **WhatsApp Community** — Join the Yaado crew for fresh music drops and discussions.

## ⌨️ Keyboard Shortcuts Reference

| Key | Action |
| :--- | :--- |
| `Space` | Play / Pause |
| `→` / `←` | Seek +5s / -5s |
| `↑` / `↓` | Volume Up / Down (+5%) |
| `L` | Like / Save song to Favorites (❤️) |
| `S` | Toggle Shuffle (🔀) |
| `R` | Toggle Repeat Mode (🔁 All / 🔂 One / ⏹ Off) |
| `N` / `P` | Next Track / Previous Track |
| `F` | Flip Cassette (Side A ⇄ Side B) |
| `/` | Open Search Bar |
